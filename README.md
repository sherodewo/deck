# AIOMI.ID Investor Deck

**Your Digital Reputation Guardian**

Nama baik Anda berharga. Kami menjaganya.

Presentasi investor interaktif berbasis browser dengan desain Metronic. Buka `index.html` atau `aiomi-id/index.html` untuk menjalankan deck.

Narasi layanan AIOMI.ID mencakup:

- **24/7 Digital Monitoring** ? Pemantauan ancaman reputasi dan penyalahgunaan identitas pada platform yang didukung.
- **Early Threat Detection** ? Deteksi dini unggahan, komentar dan aktivitas yang berpotensi merugikan.
- **Digital Evidence & Reporting** ? Dokumentasi bukti dan penyusunan laporan untuk Instagram, TikTok dan platform lainnya.
- **Platform Takedown Assistance** ? Pendampingan pengaduan, permintaan penghapusan dan tindak lanjut sesuai kebijakan platform.
- **Personal Reputation Intelligence** ? Laporan berkala ancaman, status penanganan dan perkembangan risiko.

Fitur presentasi meliputi navigasi 24 slide, Reputation Command Center interaktif, simulasi BEP, catatan pembicara, mode layar penuh, serta cetak/PDF. Gunakan tombol panah untuk navigasi, T untuk daftar isi, dan N untuk catatan pembicara.

Demo menggunakan data sintetis. Anggaran, harga dan roadmap di dalam deck merupakan asumsi/usulan investor untuk divalidasi.
